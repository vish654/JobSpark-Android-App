# JobSpark Android App

## Project Overview

JobSpark is an Android mobile application developed to help users search and apply for jobs through a simple and user-friendly interface.

## Features

- User Registration
- User Login
- Job Listings
- Search and Filter Jobs
- Job Applications
- Profile Management
- Onboarding Screens

## Technologies Used

- Android Studio
- XML Layouts
- ConstraintLayout
- LinearLayout
- Java
